⚔️ Módulo: Jugadores (/api/v1/jugadores)

GET /api/v1/jugadores RF-02 / RF-06: Listar jugadores (filtros: rol, estado, search)

Retorna la lista de todos los jugadores registrados. Soporta filtros opcionales en query params.

Query Params: 
?rol=Mid&estado=activo&search=faker
Respuesta 200 OK: 
[
  {
    "id": 1,
    "nickname": "Faker",
    "nombre_real": "Lee Sang-hyeok",
    "pais": "Corea del Sur",
    "rol": "Mid",
    "estado": "activo"
  }
]
GET /api/v1/jugadores/{id} RF-03: Ver detalle de jugador

Obtiene la información completa del jugador por ID.

Respuesta 200 OK: 
{
  "id": 1,
  "nickname": "Faker",
  "nombre_real": "Lee Sang-hyeok",
  "pais": "Corea del Sur",
  "rol": "Mid",
  "estado": "activo",
  "createdAt": "2026-10-13T00:00:00.000Z",
  "updatedAt": "2026-10-13T00:00:00.000Z"
}
POST /api/v1/jugadores RF-01: Crear jugador (RN-01: Nickname único)

Registra un nuevo jugador. Requiere rol de Admin (o cabecera x-role: Admin).

Cuerpo de Petición (JSON): 
{
  "nickname": "ShowMaker",
  "nombre_real": "Heo Su",
  "pais": "Corea del Sur",
  "rol": "Mid",
  "estado": "activo"
}
Respuestas: 
201 Created: Jugador creado exitosamente
400 Bad Request: Rol o estado inválido
409 Conflict: Nickname duplicado (RN-01)
PUT /api/v1/jugadores/{id} RF-04: Modificar datos de jugador

Actualiza campos del jugador por ID.

200 OK | 400 Bad Request | 404 Not Found | 409 Conflict (si nickname repetido)
DELETE /api/v1/jugadores/{id} RF-05: Eliminar jugador

Elimina el jugador. Sus asignaciones en rosters son removidas automáticamente.

204 No Content | 404 Not Found

🛡️ Módulo: Rosters (/api/v1/rosters)

GET /api/v1/rosters RF-08: Listar todos los rosters

Lista rosters con recuento de jugadores asociados. Filtros opcionales: tipo, temporada.

Query Params: 
?tipo=Principal&temporada=2026
Respuesta 200 OK: 
[
  {
    "id": 1,
    "nombre": "T1 Principal",
    "juego": "League of Legends",
    "tipo": "Principal",
    "temporada": "2026",
    "cantidad_jugadores": 5
  }
]
GET /api/v1/rosters/{id} RF-09: Detalle de roster con alineación

Muestra los datos del roster y sus jugadores asignados con su rol en el roster.

Respuesta 200 OK: 
{
  "id": 1,
  "nombre": "T1 Principal",
  "juego": "League of Legends",
  "tipo": "Principal",
  "temporada": "2026",

  ]

  "juego": "League of Legends",
  "tipo": "Principal",
  "temporada": "2026"

🔄 Módulo: Asignación de Jugadores a Rosters

GET /api/v1/rosters/{id}/jugadores Listar jugadores de un roster 
200 OK: Lista de jugadores con su rol_en_roster (Titular/Suplente)
POST /api/v1/rosters/{id}/jugadores RF-12 / RN-02 / RN-03: Asignar jugador a roster

Asigna un jugador como Titular o Suplente verificando que no exceda 5 titulares y no duplique rol entre titulares.

{
  "id_jugador": 1,
  "rol_en_roster": "Titular"
}
Reglas aplicadas: 
409 Conflict: Si ya hay 5 titulares (RN-02)
409 Conflict: Si ya hay un titular con el mismo rol (RN-03)
409 Conflict: Si el jugador ya está en este roster
PUT /api/v1/rosters/{id}/jugadores/{id_jugador} Cambiar rol en roster (Titular / Suplente) 
{ "rol_en_roster": "Suplente" }
DELETE /api/v1/rosters/{id}/jugadores/{id_jugador} RF-13: Quitar jugador del roster 
204 No Content: Asignación removida exitosamente
